## Décisions prises pendant le plan 2

Elles figurent dans le registre de construction, avec leur justification. Les principales :

- **Assistant capteurs.** Le service le reconnaît au propriétaire du tube nommé, qui doit être SYSTEM ou Administrateurs. Le chemin de l'exécutable ne suffit pas : il est illisible pour un programme non élevé.
- **Installation.** Le fichier XML de la tâche planifiée est préparé dans le dossier protégé de `Program Files`, et non dans le dossier temporaire de l'utilisateur.
- **Carte graphique.** Le Monitoring choisit celle qui a le plus de mémoire, pour éviter de prendre une puce intégrée.
- **UniFi.**
  - Les débits sont en bits/s ; on les divise par 8.
  - L'empreinte du certificat de la console est mémorisée à la première connexion, sous l'hôte en minuscules.
- **Client HTTP partagé** : aucune redirection suivie, pour que l'en-tête de session Freebox ne parte pas ailleurs.
- **Messages à l'écran** : tutoiement partout. Le logiciel de réglage s'appelle « le logiciel de réglage ».
- **Message du pilote CPU** : « Temp. CPU : installe le pilote », sans renvoi au README. Le plan 5 ajoutera un bouton d'installation.

## Petits points repoussés (sans urgence)

- **Réseau :**
  - l'historique est horodaté avec l'horloge murale ; un changement d'heure peut tordre la courbe ;
  - un VPN en tunnel complet peut compter le trafic deux fois.
- **Démarrage :**
  - `StartAsync` de chaque module tourne sur le fil principal avant l'icône de notification ;
  - un vidage lent du coffre peut retarder l'icône de quelques secondes.
- **Sobriété :** le tube vers l'assistant reste ouvert même sans module Monitoring à l'écran.
- **Code partagé :**
  - le dessin de texte centré, le passage d'état (`Transition`) et la levée d'événement protégée sont recopiés dans trois modules ;
  - les déplacer dans ModuleKit.
- **En écoute :**
  - le délai d'attente du verrou de rafraîchissement utilise le temps réel ;
  - une pochette lue en retard peut, rarement, gagner une course (sans conséquence durable).
- **UniFi :**
  - un rappel TLS tardif peut afficher « certificat changé » sur une autre erreur ;
  - une clé mal formée est annoncée « refusée ».
- **HardwareCheck :**
  - l'encodage d'un secret envoyé par un tuyau PowerShell 5.1 ;
  - `CryptographicException` n'est pas interceptée ;
  - plusieurs modes peuvent être combinés sur une même ligne ;
  - `--clear-secret` dit « effacé » même pour une clé absente.
- **Tests :**
  - quelques tests utilisent de petits délais réels ;
  - deux tests dépendent de la machine (cartes réseau réelles) ;
  - pas de test sur la limite exacte de 1 h de la météo.
- **Icônes météo** : 30 et 54 px ne tombent pas sur des cellules entières. Le rendu est bon à l'œil sur l'écran.
- **Assistant :**
  - un mutex squatté provoque une sortie silencieuse ;
  - la désinstallation ignore le code de retour de `/Delete` ;
  - l'installateur PawnIO est lancé sans vérifier sa signature, mais c'est l'administrateur qui donne le chemin.
