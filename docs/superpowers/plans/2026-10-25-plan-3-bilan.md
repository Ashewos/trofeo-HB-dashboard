## Décisions prises pendant les tâches 10 à 13

Chaque décision est suivie de son coût si elle est fausse.

- **Branche locale** plutôt qu'un worktree, pour qu'Alex construise et lance le service depuis le même dossier. Coût : aucun.
- **Tâche 11 découpée** : 11a pour les points repris du cloud, 11b pour le branchement. La vérification sur l'écran est menée par la session principale. Coût : aucun.
- **Modèle comparé sans suffixe.** La transcription porte `claude-opus-5-5`, alors que la barre d'état peut ajouter `[1m]`. Coût : deux variantes d'un modèle partagent la taille de fenêtre capturée.
- **Construction en Debug pendant le travail**, parce que le service d'Alex tournait depuis `bin\Release`. Release a été construit ensuite, sans avertissement. Coût : aucun constaté.
- **Raccourcis directs `Ctrl+Alt+Maj+1…9`** au lieu de `Ctrl+Alt+1…9`.
  - Sur un clavier AZERTY, AltGr vaut Ctrl+Alt. Les anciens raccourcis volaient donc `~ # { [ | \ ^` dans tout Windows.
  - `Ctrl+Alt+← / →` sont gardés : AltGr+flèche ne produit rien.
  - La spec 6.2 est mise à jour.
  - Coût : un raccourci à trois touches, modifiable dans `layout.json`.
- **Aucun raccourci enregistré** si aucun module de la disposition n'accepte de commande. Coût : un redémarrage après avoir ajouté Claude Code.
- **Exe déplacé.** La commande est réécrite seulement si son premier segment entre guillemets contient `Trofeo.StatusLine`. Coût : une commande modifiée à la main n'est pas mise à jour.
- **Fil d'activité** : pas de fondu par défaut, et le plus récent en haut, comme avant, puisque Alex n'a pas fixé de sens. Coût : un défaut à inverser s'il préfère le bas.
- **Quotas par un mod.**
  - Le mod écrit sans renommer : l'API `$.fs` ne sait pas le faire.
  - Le lecteur C# ignore un fichier à moitié écrit, donc au pire un relevé est sauté pendant une seconde.
  - La barre d'état reste disponible pour le terminal. Les deux écrivent le même fichier avec les mêmes chiffres.
  - Coût : aucun constaté.
